# 중학교 수학 한국어 어휘 콘텐츠 · 소인수분해 차시 시안

「(이주배경) 중학교 교과 적응 수학 한국어 어휘 콘텐츠」 60차시 가운데 6차시 **소인수분해** 한 차시만 따로 볼 수 있게 올린 시안입니다.

- 보기: https://j333333766-hub.github.io/math-korean-vocab-sample/
- 학습 어휘: 소인수분해, 소인수, 거듭제곱 · 미리 확인할 말: 소수(5차시)
- 영상 자리는 컷별 영상 대본으로 대신했습니다. 오른쪽 위 「제작 메모」를 켜면 화면마다 메모가 보입니다.

이 폴더의 `index.html`은 전체 시안 저장소의 `_제작도구/publish_single.py`가 만든 파일입니다. 직접 고치지 말고 원고를 고친 뒤 다시 만듭니다.

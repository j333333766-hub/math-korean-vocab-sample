0시작 전에

준비할 것 네 가지

5분
  1. Windows 컴퓨터와 인터넷. 학교 컴퓨터에서 설치가 막혀 있으면 개인 노트북을 쓰세요.
  2. Claude 계정과 결제 수단. 유료 요금제(Pro)부터 클로드 코드를 씁니다.
  3. 시작 묶음을 내려받아 둡니다. 구글 드라이브에서 받기 (92MB) → 오른쪽 화면처럼 다운로드를 누르고, 바이러스 검사 안내가 나오면 무시하고 다운로드를 누릅니다.
  4. 내가 맡은 차시 번호(대표 교사가 정해 준 담당 차시).
1구독

Claude Pro 구독하기

10분
  1. 브라우저에서 claude.ai에 들어가 가입하거나 로그인합니다. 구글 계정 로그인도 됩니다.
  2. 왼쪽 아래 이름 → 설정 → 요금제에서 Pro를 골라 결제합니다.
  3. 요금제 화면에 현재 요금제가 Pro로 보이면 끝입니다.
알아 두기Pro에는 일정 시간 동안 쓸 수 있는 양(사용 한도)이 있어요. 한도에 닿으면 몇 시간 뒤 다시 쓸 수 있다는 안내가 나옵니다.
2설치

Claude 데스크톱 앱 설치

10분
  1. claude.ai/download에서 Windows용 다운로드를 눌러 설치합니다.
  2. 앱이 열리면 로그인 → 브라우저에서 1단계 계정으로 로그인하면 앱으로 돌아옵니다.
  3. 앱 왼쪽 메뉴의 Code를 찾아 둡니다. 오늘 작업은 모두 여기서 해요.
안내가 더 나오면Code를 처음 열 때 “Git for Windows”처럼 필요한 프로그램을 설치하라고 하면, 안내 링크에서 받아 기본 설정 그대로 설치한 뒤 앱을 다시 여세요.
3폴더

작업 폴더(키트) 준비

5분
  1. 다운로드 폴더의 KSL수학어휘_시작 묶음(2026-10-20).zip을 오른쪽 클릭 → 모두 압축 풀기.
  2. 안에 있는 KSL수학어휘_차시개발키트 폴더를 문서처럼 찾기 쉬운 곳에 둡니다. 폴더 이름은 그대로.
  3. 폴더를 열어 오른쪽 그림처럼 생겼는지 봅니다. 내 차시는 차시 폴더에 생겨요.
지키기CLAUDE.md, 자료, 샘플, 틀, 도구는 직접 고치지 마세요. 작업을 시작할 때 저절로 최신으로 바뀝니다.
4열기

Code에서 키트 폴더 열기

5분
  1. 앱의 Code에서 새 작업을 시작하고, 폴더를 고르는 단추로 KSL수학어휘_차시개발키트를 고릅니다.
  2. 입력창 근처에 폴더 이름이 보이면 준비 끝.
  3. Claude가 파일을 만들거나 도구를 실행할 때 허락을 묻습니다. 키트 폴더 안의 일이면 허용을 누르세요.
편하게같은 종류를 자꾸 물으면 “이번 대화 동안 허용”처럼 묶어서 허락하는 단추를 써도 됩니다.

10분

폴더 내용을 읽고 작업 내용 파악해 줘.

인터넷 확인 실패학교망이 GitHub을 막으면 나오는 말이에요. 그대로 진행해도 됩니다.

7만들기

내 차시 만들기

15분
  1. 담당 차시 번호를 넣어 부탁합니다.
8차시 만들어 줘.
  1. Claude가 학습 어휘와 구성을 먼저 보여 주거나 몇 가지를 물어요. 대답하거나 “그대로 진행해 줘”라고 하세요.
  2. 차시\08_….html이 생기면 더블클릭해 엽니다.
  3. 위쪽 점검이 점검 ✓인지 봅니다. 숫자가 있으면 눌러 나온 글을 복사해 Claude에게 붙여 넣으세요.
성공샘플처럼 다섯 단계로 넘어가고 점검이 ✓. 영상 자리는 컷별 대본으로 나와요(영상은 업체가 만듭니다).

Code 메뉴가 보이지 않아요

요금제가 Pro인지, 앱이 최신인지 확인하고 앱을 완전히 닫았다 다시 여세요.

허락 창이 너무 자주 떠요

키트 폴더 안의 일이면 묶어서 허락하는 단추를 쓰세요. 키트 밖 폴더를 고치겠다고 하면 허락하지 말고 이유를 물어보세요.

차시 화면이 하얗고 “차시 내용을 읽지 못했습니다”만 나와요

그 글을 그대로 복사해 Claude에게 붙여 넣으세요. 빠진 따옴표나 쉼표를 찾아 고칩니다.

“사용 한도에 도달했어요”라고 나와요

Pro의 사용량을 다 쓴 거예요. 안내된 시간이 지나면 다시 쓸 수 있어요. 그동안 차시를 넘겨 보며 고칠 점을 적어 두세요.

원칙과 다르게 만들거나 엉뚱한 곳을 고쳐요

“CLAUDE.md의 원칙을 다시 읽고 지금 차시를 점검해 줘.”라고 하세요. 그래도 이상하면 새 대화를 열고 처음 문장부터 시작합니다.

실수로 차시를 망가뜨렸어요

“방금 고친 것 되돌려 줘.”라고 먼저 부탁하세요. 틀을 바꾸기 전 파일은 차시\_예전 틀\에도 남아 있어요.

학교 컴퓨터에서 설치가 안 돼요

관리자 권한이 필요한 경우예요. 개인 노트북을 쓰거나 정보 담당 선생님께 부탁하세요.

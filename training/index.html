  • Claude 계정과 결제 수단: 유료 요금제(Pro)부터 클로드 코드를 쓸 수 있습니다.
  • 시작 묶음 압축 파일: 구글 드라이브에서 KSL수학어휘_시작 묶음(2026-10-20).zip 내려받기(92MB). 링크를 열고 오른쪽 위 다운로드(↓) 단추를 누르세요. “바이러스 검사를 할 수 없는 큰 파일” 안내가 나오면 무시하고 다운로드를 누르면 됩니다.
  • 내가 맡은 차시 번호: 대표 교사가 정해 준 담당 차시(예: 8차시, 9차시).

Claude 구독하기 (Pro)

10분
  1. 브라우저에서 claude.ai에 들어가 계정을 만들거나 로그인합니다(구글 계정 로그인도 됩니다).
  2. 왼쪽 아래 이름을 누르고 설정 → 요금제(Plans)로 가서 Pro를 고르고 결제합니다.
  3. 결제가 끝나면 화면 왼쪽 아래에 요금제가 Pro로 보이는지 확인합니다.
이렇게 보이면 성공 · 설정의 요금제 화면에 현재 요금제가 Pro로 나옵니다.
알아 둘 점 · Pro에는 일정 시간 동안 쓸 수 있는 양(사용 한도)이 있습니다. 한도에 닿으면 몇 시간 뒤 다시 쓸 수 있다는 안내가 나옵니다. 연수 날에는 연습을 너무 길게 이어 가지 마세요.

Claude 데스크톱 앱 설치

10분
  1. claude.ai/download에서 Windows용을 내려받아 실행합니다.
  2. 설치가 끝나면 앱이 열립니다. 로그인을 누르면 브라우저가 열리고, 1단계에서 쓴 계정으로 로그인하면 앱으로 돌아옵니다.
  3. 앱 왼쪽 메뉴에서 Code(클로드 코드)를 찾습니다. 오늘 작업은 모두 여기서 합니다.
설치 안내가 더 나오면 · Code를 처음 열 때 “Git for Windows”처럼 필요한 프로그램을 설치하라는 안내가 나오면, 안내의 링크에서 내려받아 기본 설정 그대로 설치한 뒤 앱을 다시 여세요.
왜 데스크톱 앱인가요? · 명령어를 치는 검은 창(터미널) 없이, 폴더를 고르고 버튼으로 허락하는 방식이라 처음 쓰는 분에게 쉽습니다. 키트의 도구도 Claude가 대신 실행합니다.

Code에서 키트 폴더 열기

5분
  1. 데스크톱 앱의 Code에서 새 작업(새 세션)을 시작하고, 작업할 폴더를 고르는 단추를 눌러 KSL수학어휘_차시개발키트 폴더를 고릅니다.
  2. 입력창 위나 옆에 고른 폴더 이름이 보이면 준비 완료입니다.
허락 창이 뜨면 · Claude가 파일을 만들거나 도구(PowerShell 명령)를 실행하려 할 때 “허용할까요?”를 묻습니다. 키트 폴더 안의 작업이면 허용을 누르세요. 같은 종류를 계속 묻는 것이 번거로우면 “이번 대화 동안 허용”처럼 묶어 허락하는 단추를 써도 됩니다.
앱 화면 모습 · 단추 이름과 위치는 앱이 업데이트되면서 조금 다를 수 있어요. ‘폴더 고르기’와 ‘새 세션’ 단추를 찾으면 됩니다.

첫 대화: 작업 내용 파악시키기

10분
  1. 입력창에 아래 문장을 붙여 넣고 보냅니다.
폴더 내용을 읽고 작업 내용 파악해 줘.
  1. Claude가 먼저 세 가지를 스스로 합니다(1~2분). 허락 창이 뜨면 허용합니다.
    최신 지침 받기→차시 틀 맞추기→검토위원 전체 지침 의견 받기
  2. 지침을 읽은 뒤 작업을 두세 문장으로 설명하고, 선생님 성함과 어느 차시부터 만들지 묻습니다. 성함을 알려 주세요(차시 파일에 집필자로 적힙니다).
이렇게 보이면 성공 · “최신 지침입니다” 또는 “지침을 새로 받았어요”라는 말과 함께, 오늘의 어휘 → 뜻 알아보기 → 교과서 맛보기 → 연습하기 → 정리하기 흐름을 설명합니다.
인터넷 확인 실패라고 하면 · 학교망이 GitHub을 막는 경우입니다. 그대로 진행해도 되고, 나중에 다른 망에서 새 대화를 열면 최신 지침을 받습니다.

샘플 차시 둘러보기

10분
  1. 파일 탐색기에서 샘플\07_소인수분해(샘플).html을 더블클릭하면 브라우저에서 열립니다. 인터넷 주소로 볼 수도 있습니다: 7차시 프로토타입
  2. 왼쪽 단계 목록이나 화면 양옆 화살표로 처음부터 끝까지 넘겨 봅니다.
  3. 화면 위쪽 단추를 하나씩 눌러 봅니다.

점검

차시 내용이 약속(학습 어휘, 빠진 칸, 글 길이)에 맞는지 알려 줍니다. 점검 ✓이면 문제없고, 점검 3처럼 숫자가 보이면 눌러서 나온 내용을 Claude에게 알려 주세요.

제작 메모

화면마다 업체에 전하는 설명(개발 영역, 음원, 기회)이 보입니다.

🤖 지침 묻기

회의록과 지침을 근거로 AI에게 묻는 칸입니다. 처음 한 번 내 설정.txt의 접속 암호를 넣으세요.

💬 검토 의견

검토위원이 의견을 남기는 칸입니다. 연습 삼아 의견을 남기지 마세요(공유 시트에 그대로 쌓입니다).

활동 유형 고를 때 · 업체가 만들 수 있는 상호작용 유형을 우리 내용으로 직접 해 볼 수 있습니다: 인터랙티브 유형 보기

필요할 때 펼쳐 보세요
Code 메뉴가 보이지 않아요

요금제가 Pro인지, 앱이 최신인지 확인하세요. 앱을 완전히 닫았다 다시 열면 보이는 경우가 많습니다.

허락 창이 너무 자주 떠요

키트 폴더 안의 작업이면 묶어서 허락하는 단추(이번 대화 동안 허용 등)를 쓰세요. 키트 밖 폴더를 고치겠다고 하면 허락하지 말고 이유를 물어보세요.

차시 화면이 하얗고 “차시 내용을 읽지 못했습니다”만 나와요

그 글을 그대로 복사해 Claude에게 붙여 넣으세요. 따옴표나 쉼표가 빠진 곳을 찾아 고칩니다.

“사용 한도에 도달했어요”라고 나와요

Pro의 시간당 사용량을 다 쓴 것입니다. 안내된 시간이 지나면 다시 쓸 수 있습니다. 그동안 만든 차시를 브라우저로 넘겨 보며 고칠 점을 적어 두세요.

Claude가 엉뚱한 차시를 고치거나 원칙과 다르게 만들어요

“CLAUDE.md의 원칙을 다시 읽고 지금 차시를 점검해 줘.”라고 하세요. 그래도 이상하면 새 대화를 열고 처음 문장부터 다시 시작합니다.

실수로 차시 파일을 망가뜨렸어요

“방금 고친 것 되돌려 줘.”라고 먼저 부탁하세요. 틀을 바꾸기 전 파일은 차시\_예전 틀\에도 남아 있습니다.

학교 컴퓨터에서 설치가 안 돼요

관리자 권한이 필요한 경우입니다. 개인 노트북을 쓰거나 정보 담당 선생님께 설치를 부탁하세요.

✓

잘 부탁하는 요령

작업하면서 기억해 두세요

하나씩 부탁하기

여러 가지를 한꺼번에 말하기보다 한 가지씩 고치고 화면을 확인하면 실수가 적습니다.

위치를 번호로

화면 번호(3-2)나 단계 이름(교과서 맛보기)으로 말하면 정확히 찾아 고칩니다.

이유 묻기

“왜 이렇게 만들었어?”라고 물으면 지침의 근거를 알려 줍니다. 근거가 틀렸다면 바로잡아 주세요.
